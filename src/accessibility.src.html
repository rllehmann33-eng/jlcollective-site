What is built, stated plainly

Accessibility

This page lists what this website does today. It describes the site as built and makes no claim beyond it.

Keyboard

Links, buttons, and form fields are standard HTML elements, so each can be reached with the keyboard. The first stop on every page is a skip link to the main content. The element in focus carries a visible outline. On narrow screens, the menu closes on Escape and returns focus to the menu button.

Contrast

Text on the cream paper is set in dark ink. Text on navy is set in cream or a light gray. Each text color was checked against the background it sits on.

Motion

Nothing on this site moves on its own. Small transitions run when you hover, scroll, or press a button, and they are switched off if your device asks for reduced motion.

Interactive parts

The approval demonstration on the home page, the screen tabs on the paid media page, and the fee calculator all work with a keyboard. The tabs follow the arrow keys, and the calculator is a standard slider. The demonstration sends nothing anywhere, and without scripts the screens simply appear one after another.

The contact form

The audit form on the paid media page opens your own mail app with the request filled in. Nothing is stored on this site. The same request can be sent as a plain email to either address on the page.

Text size and structure

Zoom is not disabled, so text can be enlarged with your browser’s own controls, and the layout reflows on narrow screens. Each page has one main heading, and the headings beneath it follow in order.

Pictures of our software

The screens shown on this site are pictures of our real software, shown with demonstration data. Each one carries a written description for screen readers, and its caption says what it shows.

Reporting a problem

If something on this site does not work for you, write to luke@thejlcollective.com.
